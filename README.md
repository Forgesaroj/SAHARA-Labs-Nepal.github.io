# SAHARA LABS — official organization website

This repository publishes the official SAHARA LABS company profile at:

**https://sahara-labs-nepal.github.io/**

## Scope

The site presents:

- SAHARA LABS company purpose and operating context;
- SAHARA CORE as the flagship product in active development;
- SAHARA QR DINE and business-workflow initiatives with explicit status;
- engineering principles, technology, and public development posture;
- official GitHub and product-owner contact routes.

## Accuracy rule

The website must distinguish product direction, implementation, verification, and public release. It must not describe planned or partially tested capability as shipped, claim production readiness without evidence, or use copied third-party product branding.

## Deployment

This is a dependency-free static site. GitHub Pages publishes the root of the default branch. The `.nojekyll` file keeps delivery direct and predictable.

## Local preview

Serve the repository root with any static HTTP server, then open `index.html` through that server. No build step is required.
